# Armor

Armor in Xindeler is crafted per slot — see [Crafting](/gameplay/crafteo) for how quality tiers and materials work.

## Armor Slots

| Slot | Notes |
|------|-------|
| Head | |
| Neck | |
| Shoulders | |
| Chest | |
| Hands | |
| Ring (×2) | Two independent ring slots — you can wear two different rings at once |
| Back | Cloaks, capes |
| Belt | |
| Legs | |
| Feet | |
| Tabard | A separate cosmetic/heraldic layer, independent of your chest armor |

Beyond the 12 equipment slots above, your inventory also has 4 dedicated bag slots for carrying additional storage bags.

## Armor Sets

A selection of the sets available through crafting or looting — see [Crafting](/gameplay/crafteo) for how set requirements and quality work:

| Set | Identity |
|-----|----------|
| Adventurer | Generic starting-tier gear, no class restriction |
| Assassin | Light, stealth-oriented |
| Boreal | Cold-region, heavy insulation theme |
| Cultist | Dark, ritualistic aesthetic |
| Golemite | Heavy, construct-inspired plating |
| Leather Plate | Hybrid of leather and metal plating |
| Mail | Classic chainmail |

Each set has its own class and level requirements — check the crafting recipe or the item tooltip in-game for exact numbers, which vary by piece and quality tier.
